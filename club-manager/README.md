# Club Manager

Manages the day-to-day operation of a sports club: players, guardians,
teams, training, attendance, finance, logistics, announcements — over the
life of the club, independent of any tournament activity.

**Current status: design only, not implemented.** See
[`../docs/club-manager-design.md`](../docs/club-manager-design.md) for the
full entity/schema design, and
[`../docs/architecture-overview.md`](../docs/architecture-overview.md)
Section 3 for the module's purpose and boundaries.

First sport module to be built: Football.
